## Overview

**Toko Lokal (Luvio)** is a hyperlocal UMKM marketplace and merchant portal built with Next.js App Router (Next.js 16), React 19, Tailwind CSS v4, and Supabase ([package.json:29-37](file:///e:/bisnisPadang/package.json#L29-L37), [README.md:1-6](file:///e:/bisnisPadang/README.md#L1-L6)).

The system serves three primary user roles ([fitur.md:41-45](file:///e:/bisnisPadang/fitur.md#L41-L45)):
1. **Public Visitors / Customers**: Search UMKM stores and menus, check distance via geolocation/GPS, open store details, order via WhatsApp direct messaging, and follow QR links without requiring an account.
2. **Store Owners (Mitra)**: Authenticated dashboard to track daily visitors (by acquisition source: Google Maps, QR, Search, Direct), record daily turnover (omset) and transaction counts, update store profiles, manage menus, and configure delivery channels.
3. **Administrators**: Manage store listings, review and link free affiliate partner applications (join-afiliasi) with automated appointment slots, and generate static or time-limited dynamic QR codes (up to 15 days validity).

The application features a strict dual-mode architecture ([src/lib/catalog/server.ts:6-10](file:///e:/bisnisPadang/src/lib/catalog/server.ts#L6-L10)): when `CATALOG_MODE=demo` or if the Supabase backend is offline, the app seamlessly falls back to an embedded in-memory demo dataset ([src/lib/catalog/demo.ts](file:///e:/bisnisPadang/src/lib/catalog/demo.ts)), allowing full UI and workflow testing without active Docker or remote database dependencies.

## Data Flow

### 1. Catalog Browsing & Search
1. **User visits `/` or `/pencarian`:** The user types a keyword or clicks a category badge.
2. **Server execution ([src/lib/catalog/server.ts:6-23](file:///e:/bisnisPadang/src/lib/catalog/server.ts#L6-L23)):** `getCatalog()` checks `CATALOG_MODE`. If `supabase`, it invokes Postgres RPC `search_stores(search_text, category_slug)`. If offline or `demo`, it filters `src/lib/catalog/demo.ts`.
3. **Response rendered:** Products and store summaries are delivered to `<Catalog />` ([src/components/catalog/catalog.tsx](file:///e:/bisnisPadang/src/components/catalog/catalog.tsx)).
4. **Distance computation ([src/components/location-context.tsx:19](file:///e:/bisnisPadang/src/components/location-context.tsx#L19)):** Client-side Haversine calculation ([src/lib/location.ts:24-56](file:///e:/bisnisPadang/src/lib/location.ts#L24-L56)) computes distance in km from user coordinates to store coordinates without sending GPS data to server.

### 2. Store Order & WhatsApp Checkout Flow
1. **User opens `/toko/[slug]`:** Store profile and menu are fetched via `getStoreDetail()` ([src/lib/stores/server.ts:15-75](file:///e:/bisnisPadang/src/lib/stores/server.ts#L15-L75)).
2. **Background visit beacon:** `<VisitTracker storeId={store.id} />` ([src/components/visit-tracker.tsx:15-47](file:///e:/bisnisPadang/src/components/visit-tracker.tsx#L15-L47)) sends a non-blocking POST request to `/api/visits` with source parameter (`src=qr` or `search` or `google_maps`).
3. **Item selection:** User adds items and adjusts quantities `[-] 1x [+]` in `<StoreOrderBuilder />` ([src/components/store-order-builder.tsx:46-60](file:///e:/bisnisPadang/src/components/store-order-builder.tsx#L46-L60)). Cart is persisted in browser `localStorage`.
4. **Checkout:** User clicks checkout; a pre-formatted, numbered WhatsApp message is generated with delivery address/pickup details and total price, opening the merchant's WhatsApp chat (`https://wa.me/...`).

### 3. QR Code Resolution Flow
1. **Scan QR:** User scans dynamic QR code pointing to `https://site/q/[code]` ([src/app/q/[code]/route.ts:10-24](file:///e:/bisnisPadang/src/app/q/[code]/route.ts#L10-L24)).
2. **RPC Resolution:** Route handler invokes Postgres RPC `resolve_dynamic_qr(code)` ([supabase/migrations/202610280007_qr_codes.sql:36-49](file:///e:/bisnisPadang/supabase/migrations/202610280007_qr_codes.sql#L36-L49)).
3. **Status Check:**
   - If missing: returns 404 HTML error page.
   - If `expires_at <= now()`: returns 410 Gone HTML page ("QR sudah kedaluwarsa").
   - If active: issues HTTP 307 Temporary Redirect to `/toko/{slug}?src=qr`.

## Conventions

**Naming Conventions:**
- **Files & Directories:** Kebab-case for routes, components, and libraries (e.g., `join-afiliasi`, `store-order-builder.tsx`, `local-db.mjs`).
- **Database Tables & Columns:** Snake_case in all migrations (e.g., `daily_sales`, `appointment_date`, `cancellation_hash`).
- **Types & Interfaces:** PascalCase (e.g., `CatalogFilters`, `StoreSummary`, `StoreRecord`, `UserLocation`).
- **Server Actions:** Lower camelCase verbs exported from `actions.ts` files (e.g., `login`, `logout`, `saveStoreAction`).

**Structural Conventions:**
- **Next.js 16 App Router:** Server Components by default; `"use client"` explicit on interactive client boundaries.
- **Server Guarding:** Explicit `import "server-only";` placed at top of files dealing with server cookies, database queries, and credentials ([src/lib/catalog/server.ts:1](file:///e:/bisnisPadang/src/lib/catalog/server.ts#L1), [src/lib/auth/server.ts:1](file:///e:/bisnisPadang/src/lib/auth/server.ts#L1)).
- **Dual-Mode Graceful Fallback:** Every server query gracefully falls back to `demo.ts` if Supabase client is unavailable or returns an error.
- **Time Zone Standard:** All date-sensitive logic (daily sales, appointment booking slots, visitor stats) is strictly anchored to Western Indonesia Time (`Asia/Jakarta` / WIB) ([supabase/migrations/202610280005_admin_affiliation.sql:32](file:///e:/bisnisPadang/supabase/migrations/202610280005_admin_affiliation.sql#L32), [src/lib/portal/format.ts](file:///e:/bisnisPadang/src/lib/portal/format.ts)).
